# mogu room

食事・運動・体重を記録してキャラクターと部屋を育てる、スマートフォン対応の静的Webアプリ試作品。

- うさぎ、くま、ねこ、きつね、ぱんだの5種類
- 経験値に応じた10段階のキャラ・部屋演出
- 食事（プリセット／自由入力）、運動、体重と推移グラフ
- 減量・増量・維持モードと目安カロリー範囲の編集
- ブラウザのlocalStorageに保存（サーバー同期なし）
- 日々の目安範囲を外れても経験値は減らさず、キャラを醜くしない設計

## 起動

index.htmlを開くだけ。GitHub Pagesではリポジトリのルートから公開する。

## 注意

食事のプリセットカロリーは例示値。必要な摂取量の個人別自動算出や医療助言は未実装。端末間同期・認証・食品DB連携・アプリストア配信も未実装。
