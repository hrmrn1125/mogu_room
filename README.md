# mogu room — ピクセルアートの食事・運動育成ゲーム

モバイル優先の単一HTML/Webアプリ試作。公開先: https://hrmrn1125.github.io/portfolio_zoo/

## お世話の流れ

- ホーム画面で「ごはん」→カロリー数だけ入力。
- 入力値から、食べ物の概算エネルギーに合わせて1〜複数のエサを自動生成。200 kcal はおにぎり、700 kcal はラーメン、900 kcal はその組み合わせ。他の値には食品カタログから近い組み合わせを探索。
- エサにはカロリー数や食品名ラベルを表示せず、視覚的なイラストだけを表示。カロリー数は入力・記録ページで確認。
- 皿に並んだエサをドラッグしてキャラの口へ移動して食べさせる。タップ式の代替も利用可能。
- 運動はウォーキング、筋トレ、水泳、ダンス、ヨガ、ランニングでアクションが切り替わる。
- 5種類の食べ物×動物キャラクターを選べる。育成レベルは10段階。
- ピクセル調の庭／部屋切り替え、体重記録・推移、減量／維持／増量モード、設定済みのカロリー目安を保持。

## 栄養上の注意

食品1点のカロリー値は便宜上の代表的な一食・一個の概算。製品、レシピ、サイズにより大幅に異なるため、食事の厳密な栄養計算や食品同定には利用できない。食べた実物と生成エサが一致するわけではない。参考: [文部科学省 食品成分データベース](https://fooddb.mext.go.jp/)。

キャラは食事量の多寡で傷つかず、運動・食事記録によって成長する。医療アドバイス・必要摂取量の個別自動算出は実装していない。

データは端末のlocalStorageに保存。アカウント・端末間同期・食品データベースAPI連携は未実装。
