# mogu room — 食べて、育てる小さなおへや

スマートフォンを第一に設計した、食事・運動・体重記録付きの育成ゲームのプロトタイプです。純粋な HTML / CSS / JavaScript / インラインSVG で動作します。

## 遊び方
1. ホーム画面の「ごはんを記録」で食べたもの・カロリーを登録する。
2. 登録した食事がSVGのエサとして、おさらに出現する。
3. エサを指またはマウスでドラッグし、キャラの口の近くで離すと食べる。タップして「食べさせる」ボタンを使う代替操作も可能。
4. 食べさせたり運動を記録したりすると育成ポイントが増え、10段階でキャラや家具が育つ。
5. 体重は別ページで日付別に記録し、折れ線グラフで確認する。

## キャラ
- ケーキいぬ
- おにぎりうさ
- プリンひよこ
- メロンくま
- だんごねこ

既存作品をトレースしないオリジナルSVGキャラクターです。装飾・スケール・家具・植物などは成長レベルに応じて変化します。アイコン・食べ物もSVGで描画し、絵文字は使いません。

## モードと保存
減量・維持・増量モード。目安カロリーは任意に編集できますが、食べ過ぎや運動不足で経験値を失うことはありません。医療上の推奨カロリーを自動算出する機能はありません。保存はlocalStorageのみで、認証や端末間同期は未実装です。

前バージョンの食事・運動・体重データは、同じブラウザに残っていれば初回のみ読み込む設計です。旧データの食事は食べ終わったものとして扱います。

## 起動
GitHub Pagesでリポジトリルートの `index.html` を公開するか、ローカルで直接開きます。ビルド不要です。
