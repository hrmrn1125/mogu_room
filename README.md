# mogu room — 食事と運動で育てるドット絵キャラ

Webアプリ: https://hrmrn1125.github.io/portfolio_zoo/

## キャラクターと見た目
承認済みのイラスト4体を使用しています。ドット絵用の自動輪郭変形は描画に使用しません。

- ラベンダーうさぎ（星付きナイトキャップ）
- ピーチりす（水色の星風船）
- ほしのハリネズミ（紫の星バッグ）
- ペリウィンクルカワウソ（黄色い星）

画像は `mascot-art.js` 内のWebP素材で保持し、ホームと設定のキャラ選択で共用しています。画像の輪郭や色は変更せず表示します。タップするとキャラの口ぐせで話しかける仕組みは維持しています。体型別のイラスト差分はこの新しい画風ではまだ未制作のため、現段階では4体とも承認済みの通常体型のみ表示します。

## 記録と操作
- 「ごはん」からカロリー数を入力すると複数のエサに変換。指でドラッグしてキャラの口元に運ぶと食べる。
- ゲージは **食べさせたカロリー − 当日の運動による推定消費カロリー**（0未満は0表示）。運動するとゲージが下がります。体型別の新イラストは未実装です。
- 「運動」はウォーキング、筋トレ、水泳、ダンス、ヨガの5種類。記録後、歩行・ダンベル・水泳などのアニメーションを短時間表示。
- ゲージ横の「リセット」で当日の食事・給餌・運動記録・残りのエサを削除し、0 kcalに戻す。リセットには確認ダイアログが出る。
- ブラウザの現地日付が変わると、日付ごとのゲージが0に戻り、前日の未給餌エサが消える。タブ復帰時にもチェック。
- 身長・体重・年齢・性別・活動量を変更して保存すると、目安を再計算するとともに当日の記録をリセット。
- 体重記録は履歴を残し、プロフィール体重を変更した場合はその日の記録もリセット。

## 注意
カロリーと運動消費量、減量・維持・増量の境界はゲーム内の推定値です。医学的な摂取推奨量ではありません。運動の消費量を食事量から差し引くゲージは、実際の体重変化や健康状態を表しません。急な減量や過度な運動を推奨しない設計です。

保存はブラウザのlocalStorage。ログイン、クラウド同期、決済は未実装です。背景のプレミアム表示は課金機能のプレビューのみ。
